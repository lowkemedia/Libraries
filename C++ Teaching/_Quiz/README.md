# C++ quizzes and answer keys

[Back to the course guide](../README.md)

Three classroom quizzes provide short written questions, code-reading exercises and a small programming task. Use the question PDFs first, then compare your reasoning with the separately linked keys. Each PDF also has editable Pages and ODT versions in its folder.

| Quiz | Topics | Questions | Answer key |
| --- | --- | --- | --- |
| A | Unix commands, types, constants, operators, console I/O, escapes, comments and syntax | [Quiz A](quiz_a/QuizA.pdf) | [A solutions](quiz_a/solution/QuizA%20solution.pdf) |
| B | Boolean expressions, assignment vs equality, branching, loops, math functions, functions and scope; writing a multiplication table | [Quiz B](quiz_b/QuizB.pdf) | [B solutions](quiz_b/solution/QuizB_solution.pdf) |
| C | Compound assignment, arrays, default arguments, overloads, enums, strings, random seeds, namespaces, searching and references | [Quiz C](quiz_c/QuizC.pdf) | [C solutions](quiz_c/solution/QuizC_solution.pdf) |

As a self-study guide, try A after topics 00–06, B after 07–11, and C after 12–18. These are suggested review points based on the questions, not an asserted original assessment schedule.

Quiz B also includes [a C++ multiplication-table solution](quiz_b/solution/quizB_q20.cpp). Its filename refers to question 20, while the checked-in question PDF labels the table task 18; match it by the task rather than the number.

Some questions intentionally contain faulty code. Predict its behaviour or identify the fault before running it. These are original classroom questions and answer keys, not an automated test suite; no comprehensive correctness review of the keys is claimed here.
