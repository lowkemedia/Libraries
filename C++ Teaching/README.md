# Learn C++: notes, exercises and projects

Teaching materials assembled by **Russell Lowke while teaching C++ at the Seattle Art Institute**, for **SDVA103 C++ Programming I** and **SDVA203 C++ Programming II**. Shared here for independent learners, teachers and anyone who enjoys learning programming by writing small programs.

The collection runs from a first console program through functions, arrays, pointers, classes, inheritance and templates. It contains **34 numbered topic folders**, **30 homework exercises with solution folders**, **three quizzes with answer keys**, an **eight-part chess exercise**, and **two final-project briefs**. The lecture notes are available as PDFs alongside editable Apple Pages and OpenDocument Text (ODT) files.

## Start here

1. Follow [Getting started](02%20Getting%20Started/README.md) to compile and run `hello.cpp`.
2. Work through the numbered topics below. Read the PDF, then type or run a small example and change it to see what happens.
3. Try the homework before opening its `solution` folder. Alternative solutions are useful comparisons, not additional files to combine into one program.
4. Use the [quizzes](_Quiz/README.md) to check your understanding. Try [chess parts 1–3](_Chess%20Example/README.md) after control flow and functions, then return to parts 4–8 as you learn classes and inheritance.
5. Choose a [final game project](_Final%20Project/README.md) to bring the ideas together.

Already comfortable with the basics? Start with references and pointers (18–21), classes (25), or the chess exercise. The topic numbers provide a reading order; they are not a week-by-week timetable for either course.

## Files and tools

`.pdf` files are the easiest way to read or print the notes. `.pages` files are the Apple Pages originals, and `.odt` files are editable OpenDocument Text versions. `.cpp`, `.h` and `.hpp` files are plain-text C++ source. Later chess stages include makefiles. The `.BAS` files under the final project are BASIC, not C++.

The examples are separate console programs, many with their own `main()`. Build one example or one project directory at a time. A C++11-capable compiler is needed for features used here, including range-based loops and `override`; the [getting-started guide](02%20Getting%20Started/README.md) explains the commands and platform limits. These materials do not require Unity or the sibling C++ utilities.

PDF, Pages and ODT documents are stored using Git LFS. If a cloned document contains a short `version https://git-lfs.github.com/spec/v1` text record instead of opening normally, its large-file contents have not been downloaded. With Git LFS available, run this from the repository root to fetch this collection:

```sh
git lfs pull --include="C++ Teaching/**" --exclude=""
```

## Using this classroom collection

The original notes, exercises and solutions are retained as teaching material, including their naming, conventions and occasional rough edges. Read small examples in the context of the lesson: they are not a production library or a comprehensive modern C++ reference. Platform-specific setup instructions and classroom policies may no longer match your environment. Compiler warnings and observed behaviour are useful things to discuss and investigate.

Keep existing author credits and source references with reused material. In particular, the final-project BASIC examples have their own [source attribution](_Final%20Project/basic_games/_info.txt).
