# C++ Animator

This C++ animator is an earlier version in the lineage of
[Animatem](../../../../Unity/General/Animatem/README.md), Lowke Media's Unity
animation utility. Animatem began in Lingo for Macromedia Director; this C++ code
is retained as historical reference. See the
[SVN archive guide](../../../../README%20SVN%20Archives.md) for the preserved later
repositories and source downloads.
