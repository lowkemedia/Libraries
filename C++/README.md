# C++ resources

Looking to learn C++? Start with **[C++ Teaching](C%2B%2B%20Teaching/README.md)**, Russell Lowke's teaching collection from the Seattle Art Institute. It includes a linked sequence of 34 topics, PDF notes, examples, homework and solutions, quizzes, an eight-part chess exercise and final game projects.

The teaching collection is self-contained: it does not depend on the other folders here. [C++/src](C%2B%2B/src/) contains separate matrix/utility and OpenGL/GLUT animator code; `Mersenne Twister` is another separate historical source collection.
