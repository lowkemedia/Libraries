# Historical SVN archives

These Google Code archives preserve earlier Lowke Media utilities hosted in
Subversion (SVN). They are historical reference material; the current libraries
are described in the [main README](README.md).

The original repository addresses followed the pattern
`https://PROJECT.googlecode.com/svn/`. Use the archive pages and ZIP downloads
above to access the preserved material. Extract a ZIP into a separate folder to
explore it; the inspected archives contain source under `PROJECT/trunk/`.
Preserve each file's copyright, licence and third-party attribution notices.

## Dates and scope

Google Code project hosting operated from [2006 to 2016](https://code.google.com/).
The archived project metadata dates the creation of
[`lowke`](https://storage.googleapis.com/google-code-archive/v2/code.google.com/lowke/project.json)
and
[`lowke-animator`](https://storage.googleapis.com/google-code-archive/v2/code.google.com/lowke-animator/project.json)
to August 2011. Those are hosting dates, not the original development dates of
all the code.

The archived commit listings end at
[`lowke` revision 193, 27 April 2015](https://storage.googleapis.com/google-code-archive/v2/code.google.com/lowke/commits-page-1.json),
and
[`lowke-animator` revision 22, 7 July 2013](https://storage.googleapis.com/google-code-archive/v2/code.google.com/lowke-animator/commits-page-1.json).
The latter records the rename from Animatem to Animator in July 2013, which
explains both names appearing in the archive.

The four project identities were confirmed against surviving local SVN working
copies. All four source download links responded when checked on 18 November
2026; the `lowke` and `lowke-animator` ZIPs were also downloaded and inspected.
These ZIPs have not been verified as complete SVN history backups. No build or
runtime verification of the archived code is implied.

## Earlier Director / Lingo version

Animatem was originally written in Lingo for Macromedia Director, before the
later C++, ActionScript and Unity versions. MOCAZ was Russell Lowke's company
name before Lowke Media, and appears in the earlier code's attribution. Lowke
Media retained the MOCAZ logo.

The [Director / Lingo Animatem](Director/Animatem/README.md) is preserved in this
repository as an unchanged copy of
[`ANIMATEM_1_02.DIR`](Director/Animatem/ANIMATEM_1_02.DIR). This is
a Director movie containing readable Lingo source, with 1998 MOCAZ copyright
notices. Earlier animator source in Frogger records an authorship date of
2 November 1995.

These are source dates, not confirmed publication dates. The original online
repository remains unidentified; the Google Code links above preserve later
versions.
